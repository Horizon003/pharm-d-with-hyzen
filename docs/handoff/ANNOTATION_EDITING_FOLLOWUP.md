## Changes

The existing annotation screen now has a raised, collapsible contextual dock. Select/move, Pen, Highlight and Text are quick actions; More groups all existing tools into Navigate, Markup, Shapes and Notes. A scrollable style sheet controls color, stroke size and actual opacity for new marks. Controls sit outside the page gesture area. Typed signatures remain visual annotations, not certified signatures.

Undo/Redo now restores complete annotation states for drawing, text placement, move and deletion, rather than treating deletion of the last mark as Undo. History is page-scoped and bounded to20 checkpoints per page during the current editor session. Undo history is not persisted across restarts; the resulting edit layer is persisted. Confirmed Discard session edits restores the layer read when the editor opened, preserving earlier annotations and the original PDF.

Annotation writes queue immutable snapshots by private edit-layer path, shared between editor instances. Reopening waits for that path’s earlier queue before reading the layer. Rapid edit/Undo writes cannot finish out of order. Save only reports success after native acknowledgment and local-history update; false acknowledgment is now treated as failure. Failure retains the session layer, reports an error and allows explicit retry. Export waits behind queued writes and still composes a separate PDF copy; existing files and prior edit layers are not deleted. This serialization applies to this annotation editor, not every native operation in the application.

Optional opacity is persisted on new marks and honored in vector annotation export and the existing raster rendering path. Legacy marks without opacity retain native default highlight/non-highlight behavior. No destructive schema migration or stored-file cleanup occurs. Empty/unreadable documents and failed page renders keep editing/export controls unavailable until a real page loads.

Changed source: studio_annotation_screen.dart, studio_pdf_engine.dart, StudioDocumentOps.kt, StudioPdfEngine.kt; tests studio_annotation_test.dart and StudioDocumentOpsTest.kt; isolated screenshot capture workflow. Phase05 owns the annotation UI/new tests. The camera overlay owns the shared engine/native paths, updated by exact path only. Final assembly matches80 owned paths.
