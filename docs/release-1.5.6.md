# PHARM D WITH HYZEN 1.5.6 — Pastel Reference Edition

A native Flutter redesign following the supplied education/productivity UI
references: Poppins typography, lavender/mint/pink gradient feature cards,
photographic onboarding, compact pill buttons and a five-tab dock.

Light mode replaces dark mode. Existing study/account data, goals, tasks,
reminders, rankings, downloads, document tools, Firebase/OneSignal, shop and admin
features are retained. Install as an update; do not uninstall to keep local data.

Package `com.hyzen.pharmd` · version `1.5.6` · build `15` · original signing key ·
universal ARM32, ARM64 and x86_64 APK. Checksums and build provenance are attached.

The exact source reference font was not identifiable; Poppins provides the
licensed geometric match. The student portrait and three illustration assets
were generated for this app. Hyzen's panda is retained.

Physical-device smoothness, camera/OCR quality, battery and live account/push
verification remain pending. A guaranteed 60 FPS result is not claimed.
